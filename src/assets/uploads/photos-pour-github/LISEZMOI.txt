PHOTOS PRÊTES POUR GITHUB
=========================

Toutes ces photos sont redimensionnées pour le web (2400 px max) et
sans données cachées (position GPS, appareil…).

Où les déposer : glisser tous les fichiers .jpg (pas ce fichier texte) sur
https://github.com/hugopayenhc-dot/portfolio-aziliz/upload/main/src/assets/uploads
puis cliquer sur « Commit changes ».

Ensuite, dans l'admin, pour chaque œuvre : Photos → Ajouter photos →
Choisir une image → la photo est déjà dans la médiathèque.
